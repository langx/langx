# Plans

Working plans Claude wrote between 28 August and 5 September 2026, kept because
they carry the reasoning that the commits compress away. They are records, not
instructions: each one describes the state of a piece of work on the day it
was written, and the status section at the top says how far it got. Nothing
here is updated when the code moves on — read them with the date in mind.

The files in this folder were rewritten by hand with a status section and are
the ones worth reading first. `session-store/` holds the raw, machine-named
plans behind them, one per session, in the state the session left them.

They lived in a folder outside every git checkout until 5 September 2026 and
were moved here so a machine change does not lose them.
