# Plans

Working plans Claude wrote while building v2, kept because they carry the
reasoning that the commits compress away. They are records, not instructions:
each one describes the state of a piece of work on the day it was written, and
the status section at the top says how far it got. Nothing here is updated
when the code moves on — read them with the date in mind.

Session handoffs and the raw per-session plan files were removed on
5 September 2026: they named machines and paths that do not belong in a
public repository. What they decided is in the commits and in
[`decisions.md`](../decisions.md).
